# AI-Powered Тестовый Бот (Vertex AI)

## 🤖 Интеллектуальное тестирование

Этот бот использует **Vertex AI (Gemini)** для генерации реалистичных ответов клиента в реальном времени.

## Отличия от обычного тестового бота

| Обычный бот | AI-powered бот |
|-------------|----------------|
| Заранее заготовленные сообщения | Генерирует ответы в реальном времени |
| Один фиксированный сценарий | Адаптируется к ответам бота |
| Не учитывает контекст | Анализирует всю историю диалога |
| Все клиенты одинаковые | Разные типы клиентов (вежливый, занятой, нерешительный) |

## Что он делает?

1. **Получает сообщение от бота** → анализирует
2. **Генерирует ответ через Vertex AI** → учитывая:
   - Цель сценария
   - Историю диалога
   - Тип личности клиента
3. **Отправляет естественный ответ** → продолжает диалог
4. **Автоматически завершает** → когда бот подтверждает запись
5. **Сохраняет логи** → каждого диалога в `test-logs/`

## Настройка

### 1. Проверьте `.env`

Убедитесь что есть настройки Vertex AI:
```bash
VERTEX_PROJECT_ID=gen-lang-client-0728954141
VERTEX_LOCATION=us-central1
```

### 2. Настройте номер бота

Откройте `test-bot.js` и укажите номер основного бота:
```javascript
const CONFIG = {
  BOT_NUMBER: '77774051062@s.whatsapp.net', // Ваш номер
  AI_RESPONSE_DELAY: 2000,  // Задержка ответа (имитация набора)
  MAX_MESSAGES_PER_SCENARIO: 15,  // Максимум сообщений
  SCENARIO_DELAY: 15000,  // Пауза между сценариями
};
```

## Тестовые сценарии

Бот протестирует 5 сценариев с разными типами клиентов:

### 1. **Вежливый клиент**
- Цель: Запись к Айгерим завтра на 10:00
- Услуга: Маникюр с укреплением
- Поведение: Дружелюбный, использует приветствия

### 2. **Занятой клиент**
- Цель: К Юне через 2 дня в 14:00
- Услуга: Наращивание ногтей типсы
- Поведение: Краткие ответы, по делу

### 3. **Требовательный клиент**
- Цель: 10 февраля в 16:00 к Айгерим
- Услуга: Снятие покрытия
- Поведение: Задает много вопросов

### 4. **Новый клиент**
- Цель: Сегодня вечером 18:00 к Юне
- Услуга: Маникюр без покрытия
- Поведение: Не знает всех услуг, спрашивает

### 5. **Нерешительный клиент**
- Цель: Завтра, меняет время с 15:00 на 17:00
- Услуга: Маникюр к Айгерим
- Поведение: Передумывает, меняет решение

## Что проверяется?

✅ **Естественный диалог** - AI генерирует реалистичные ответы  
✅ **Контекст** - учитывается вся история разговора  
✅ **Адаптивность** - бот реагирует на вопросы и предложения  
✅ **Разные форматы** - даты, времени, названий услуг  
✅ **Личности клиентов** - разные стили общения  
✅ **Календарь** - события создаются с правильной датой/временем

## Troubleshooting

**❌ "Vertex AI не инициализирован"**
- Проверьте `.env`: `VERTEX_PROJECT_ID` и `VERTEX_LOCATION`

**❌ "Бот не отвечает"**
- Убедитесь что основной бот работает (`npm start`)
- Проверьте правильность номера в `BOT_NUMBER`

**❌ "AI генерирует странные ответы"**
- Увеличьте `AI_RESPONSE_DELAY` (даст больше времени на обработку)
- Проверьте что сценарий четко описан
