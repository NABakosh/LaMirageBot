## Инструкция: Добавление календаря для нового мастера

Когда потребуется добавить календарь для другого мастера, выполните следующие шаги:

### 1. Получите/создайте Gmail для мастера

Попросите мастера предоставить email Gmail или создайте новый аккаунт.

### 2. Обновите `.env`

Откройте файл `.env` и найдите секцию `GOOGLE CALENDAR - MASTER EMAILS`.

Для мастера, например, Аружан:
```bash
CALENDAR_АРУЖАН=arujan.master@gmail.com
```

### 3. Предоставьте доступ сервисному аккаунту

**Важно!** Мастер должен дать доступ к своему календарю:

1. Откройте [Google Calendar](https://calendar.google.com)
2. Войдите под аккаунтом мастера
3. Нажмите на "⚙️ Настройки" → "Настройки календаря"
4. Выберите основной календарь
5. Прокрутите до "Доступ для отдельных пользователей"
6. Нажмите "+ Добавить пользователей"
7. Введите email: `lamirageintegration@integration-481605.iam.gserviceaccount.com`
8. Выберите права: **"Вносить изменения в мероприятия"**
9. Нажмите "Отправить"

### 4. Перезапустите бота

```bash
npm start
# или если используете PM2:
pm2 restart main
```

### 5. Протестируйте

Создайте тестовое бронирование к этому мастеру и проверьте что событие появилось в его календаре.

---

**Готово!** Теперь все записи к этому мастеру будут автоматически создаваться в его личном календаре.

## Примечания

- **Приватность:** Каждый мастер видит только свои записи
- **Одна настройка:** Не нужно менять код, только `.env`
- **Graceful fallback:** Если email не указан, бронирование работает как обычно, просто без календаря
